Vishwas Billing privacy policy

New Vishwas Enterprises operates Vishwas Billing as a private desktop app for the shop’s billing records.

Permission and data accessed

The shop owner can authorize Gmail read-only access through Google. Google grants this permission at the mailbox level. The app checks the email address to confirm it is connected to the shop mailbox, verifies the dedicated Vishwas Billing label, and searches that label for billing PDFs or Meta business receipt messages. During setup it reads the shop’s label names and IDs to locate the dedicated label.

For matching messages, the app fetches the message details, which can include Gmail message IDs, labels, timestamps, headers, body content and attachment details. It reads the body of supported Meta Ads receipts and downloads PDFs from matching messages for validation. Billing data can include account, invoice and transaction references, amounts, taxes and payment references. All mailbox operations use read-only Gmail API methods.

Use and storage

The app uses Gmail data to identify and validate billing evidence, avoid counting the same document twice, compare bills and payments, and prepare a local report for the shop owner. The Windows app saves the refresh credential and label ID locally so it can run after the initial authorization. The local billing ledger retains accepted PDF files, decoded text and identifiers from accepted receipts, extracted billing fields, dates, and evidence hashes. Unsupported evidence is rejected. The app can retain its hash and rejection reason.

The ledger and generated HTML, JSON and CSV reports are kept on the shop computer under its Windows user account. Copies remain there until they are removed. Removing a Gmail label or revoking access leaves existing local copies in place.

Sharing and limited use

The Windows app communicates with Google to authorize access and retrieve the selected billing evidence. The retrieved evidence stays on the shop computer. New Vishwas Enterprises limits its use of the Gmail data to the shop owner’s billing records.

Vishwas Billing uses information received from Google APIs in accordance with the Google API Services User Data Policy, including its Limited Use requirements.

Disconnect Gmail or remove local copies

The shop owner can revoke Vishwas Billing’s access from Google Account connections. This stops future Gmail access. To remove the saved connection from the shop computer, delete the app’s local Gmail credential. The default location is %LOCALAPPDATA%\Vishwas\Billing\credentials\gmail_authorized_user.json.

Contact shop support for help accessing the local HTML, JSON or CSV report or removing stored copies. To clear the app’s complete local billing history, stop the billing task and remove the local billing database, any database sidecar files, and the generated reports from %LOCALAPPDATA%\Vishwas\Billing. This also removes billing history from other sources kept in those files. Review applicable accounting retention requirements before removing records and review any copies exported separately. Gmail originals stay in Gmail. If the connection remains active, later runs can import messages still carrying the billing label.
